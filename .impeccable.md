# Design context

## Target audience
Quality inspectors, lab engineers and students who run a machine-vision surface-defect prototype on a local machine. They need to upload a bottle image, adjust a few inference parameters and interpret detection results quickly. Basic CV knowledge, but not UI designers.

## Use cases
1. Upload / drag in a single bottle image and run defect detection.
2. Tune confidence threshold, NMS IoU and input size; inspect model path.
3. Read clear results: defect class, confidence, bounding-box coordinates, or an explicit "product intact" state.
4. Review model metrics, dataset composition and usage guidance without leaving the app.

## Brand personality / tone
Industrial precision, calm trustworthiness, data-dense but breathable. Not playful, not cyberpunk, not dark-mode gaming. A polished instrument panel: cool blue primary, tinted neutrals, precise typography, restrained elevation, generous spacing where it aids scanning.

## Constraints
- Streamlit 1.67 single app, custom CSS injection, no external component framework.
- Keep existing detection functions, business flow and data interfaces unchanged.
- WCAG AA contrast, visible focus, keyboard operability, responsive down to 320px.
- Light theme (matches IDE and industrial QA setting).
